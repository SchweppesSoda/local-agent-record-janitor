# Apply 性能基线

本文件只记录匿名性能数据，不记录 thread ID、聊天正文或用户目录。

## 2026-08-19 基线

- 场景：单一 Codex 物理存储中的 53 个根删除动作。
- 总耗时：901.777 秒。
- 平均耗时：约 17.015 秒/动作。
- 已确认瓶颈：执行前已有一次完整快照，但逐 action guard 又调用完整
  adapter 扫描和完整计划构建，形成 `N × 全库扫描`。

## 重构验收目标

- `plan` 只做一次完整快照。
- `apply` 固定一次完整预检和一次完整终检。
- 每个 action 只读取与其物理存储、记录身份、活动引用和关联范围有关的证据。
- 100 个 action 的 apply 必须保持两次完整扫描；测试直接统计扫描调用次数。
